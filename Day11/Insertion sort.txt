Insertion sort
-> simplest string algorithm
-> insertion sort is like "You can take one element at a time and insert it into it's correct position in already sorted part.

Eg: arr=[5,3,4,1]
step-1 : [5]-> sorted array
step-2 : insert '3' 
		[3,5]=> sorted
step-3 : insert '4'
		[3,4,5]=> pushing 5 to right side
step-4: insert '1'
	shifting all numbers -> [1,3,4,5]

Inserting sort process:

-> assume the 1st element is already sorted.
-> pick the next element
-> compare it with previous elements
-> shifting large elements to the input
-> inserting the element at a current position.

Time complexity
case       Complexity
Best       0(n)already sorted
Average    0(n^2)
Worst      0(n^2)

Space complexity => 0(1) in place sorting
